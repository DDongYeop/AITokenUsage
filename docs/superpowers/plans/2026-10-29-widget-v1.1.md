# AI 사용량 위젯 v1.1 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**목표:** 위젯에 초기화까지 남은 시간을 표시하고, 한국어·영어를 지원하고, 설정 창을 Windows 11 스타일 페이지 구조로 바꾸고, Inno Setup 설치 프로그램을 만든다.

**구조**
- 사용자 문자열을 Core와 App의 강타입 `.resx`로 옮긴다. 기본은 영어, `ko`는 한국어다.
- 언어는 앱 시작 시 한 번 정한다.
- 남은 시간·연결 안내·시작 등록 동기화 같은 판단 로직은 Core의 순수 함수로 두고 단위 테스트한다. WPF 쪽은 그 결과를 그리기만 한다.
- 설치 프로그램은 self-contained publish 결과를 Inno Setup으로 묶는다.

**기술 스택:** C#/.NET 10 (SDK 10.0.401), WPF (.NET 10 Fluent `ThemeMode`), xUnit 2.9.3, MSBuild 강타입 resx, Inno Setup 6

**설계 문서:** `docs/superpowers/specs/2026-10-29-widget-v1.1-design.md`(v1.1 설계). 그 문서가 기준으로 삼는 `docs/superpowers/specs/2026-10-28-ai-usage-taskbar-widget-design.md`(v1.0 설계)도 함께 따른다.

## 전체 제약 (모든 Task에 적용)

**보안**
- CLI 자격 증명 파일(`~/.claude/.credentials.json`, `~/.codex/auth.json`, `~/.gemini/oauth_creds.json`)에는 절대 쓰지 않는다. Claude·Codex 토큰을 갱신하지 않는다.
- 토큰, 원본 API 응답 본문, 자격 증명을 로그·캐시·화면에 남기지 않는다.
- Google OAuth 클라이언트 ID·시크릿 리터럴을 저장소에 넣지 않는다(GitHub Push Protection).

**실행 환경에서 하지 않는 것**
- 실제 입력(`mouse_event`, `SendInput`, `SendKeys`, `SetCursorPos`, UIA `Invoke`로 사용자 화면 조작)을 보내지 않는다. 화면 확인은 `PrintWindow`/창 캡처로만 한다.
- 탐색기 재시작, Windows 설정 변경, GitHub 로그인, 시작 등록을 영구로 켜기를 하지 않는다.
- push를 하지 않는다. 커밋은 Phase 끝에 컨트롤러가 한다. **구현 담당은 커밋하지 않는다.**

**코드 규칙**
- 기존 코드 스타일을 따른다: file-scoped namespace, `sealed`, XML doc 주석 밀도, `ArgumentNullException.ThrowIfNull`
- 빌드 경고는 0을 유지한다. `dotnet build AITokenUsage.sln`과 `dotnet test AITokenUsage.sln`이 모두 통과해야 한다.
- 로그 메시지는 영어로 둔다. 설정 파일 키와 미터 키(`session`, `weekly` 등)는 바꾸지 않는다.
- 리소스 키 이름은 PascalCase `<영역><의미>`로 짓는다. 예: `StatusConnected`, `WidgetEmptyTitle`, `GuideCodexLogin`
- 자리표시자 문구는 `string.Format(CultureInfo.CurrentCulture, Strings.X, …)`로 만든다.
- **위젯 폭**: 남은 시간이 켜져 있으면 210 DIP, 꺼져 있으면 176 DIP. 높이는 40 DIP다.
- **짧은 남은 시간 형식**(v1.1 설계 §2.2): `<1m`, `42m`, `4h12m`/`4h`, `2d3h`/`2d`, `12d`. 초기화 시각이 없으면 빈 문자열이다.
- **용어집**: 영어 문구를 쓸 때 이 표를 따른다.

  | 한국어 | 영어 |

  | 연결됨 | Connected |

```csharp
// src/AITokenUsage.Core/Localization/LanguageResolver.cs
using System.Globalization;
using AITokenUsage.Core.Settings;

namespace AITokenUsage.Core.Localization;

/// <summary>Maps the "Language" setting (auto/ko/en) and the Windows UI language to the app culture (v1.1 spec §3.2).</summary>
public static class LanguageResolver
{
    public static string Normalize(string? setting) => (setting ?? "").Trim().ToLowerInvariant() switch
    {
        AppSettings.LanguageKorean => AppSettings.LanguageKorean,
        AppSettings.LanguageEnglish => AppSettings.LanguageEnglish,
        _ => AppSettings.LanguageAuto,
    };

    public static CultureInfo Resolve(string? setting, CultureInfo osUiCulture)
    {
        ArgumentNullException.ThrowIfNull(osUiCulture);

        string language = Normalize(setting);
        if (language == AppSettings.LanguageAuto)
        {
            language = osUiCulture.TwoLetterISOLanguageName == "ko" ? AppSettings.LanguageKorean : AppSettings.LanguageEnglish;
        }

        return CultureInfo.GetCultureInfo(language == AppSettings.LanguageKorean ? "ko-KR" : "en-US");
    }
}
```

- 속성을 추가한다.

```csharp
// tests/AITokenUsage.Core.Tests/Localization/ResourceCompletenessTests.cs
using System.Text.RegularExpressions;
using System.Xml.Linq;

namespace AITokenUsage.Core.Tests.Localization;

/// <summary>Every neutral (English) key must exist in the Korean file, be non-empty and use the same {n} placeholders.</summary>
public partial class ResourceCompletenessTests
{
    public static TheoryData<string> ResourceBases => new()
    {
        Path.Combine("src", "AITokenUsage.Core", "Resources", "Strings"),
        Path.Combine("src", "AITokenUsage", "Resources", "UiStrings"),
    };

    [Theory]
    [MemberData(nameof(ResourceBases))]
    public void Korean_resources_match_neutral_resources(string relativeBase)
    {
        string root = RepoRoot();
        string neutralPath = Path.Combine(root, relativeBase + ".resx");
        if (!File.Exists(neutralPath) && relativeBase.Contains("UiStrings", StringComparison.Ordinal))
        {
            return; // App resources arrive in Task 4.
        }

        Dictionary<string, string> neutral = Load(neutralPath);
        Dictionary<string, string> korean = Load(Path.Combine(root, relativeBase + ".ko.resx"));

        Assert.NotEmpty(neutral);
        Assert.Empty(neutral.Keys.Except(korean.Keys));
        Assert.Empty(korean.Keys.Except(neutral.Keys));
        foreach ((string key, string value) in neutral)
        {
            Assert.False(string.IsNullOrWhiteSpace(value), $"empty neutral value: {key}");
            Assert.False(string.IsNullOrWhiteSpace(korean[key]), $"empty Korean value: {key}");
            Assert.Equal(Placeholders(value), Placeholders(korean[key]));
        }
    }

    private static Dictionary<string, string> Load(string path) =>
        XDocument.Load(path).Root!.Elements("data")
            .ToDictionary(e => (string)e.Attribute("name")!, e => (string?)e.Element("value") ?? "");

    private static string Placeholders(string value) =>
        string.Join(",", PlaceholderRegex().Matches(value).Select(m => m.Groups[1].Value).Distinct().Order());

    private static string RepoRoot()
    {
        for (DirectoryInfo? dir = new(AppContext.BaseDirectory); dir is not null; dir = dir.Parent)
        {
            if (File.Exists(Path.Combine(dir.FullName, "AITokenUsage.sln")))
            {
                return dir.FullName;
            }
        }

        throw new InvalidOperationException("AITokenUsage.sln not found above the test output directory.");
    }

    [GeneratedRegex(@"\{(\d+)(?:[,:][^}]*)?\}")]
    private static partial Regex PlaceholderRegex();
}
```

```csharp
using System.Diagnostics;
using System.Globalization;
using System.Windows;
using AITokenUsage.Core.Localization;

namespace AITokenUsage;

/// <summary>Applies the UI language once at startup and restarts the app when the user changes it (v1.1 spec §3.2).</summary>
public static class LanguageBootstrap
{
    public const string RestartedArgument = "--restarted";

    public static CultureInfo Apply(string? languageSetting)
    {
        CultureInfo culture = LanguageResolver.Resolve(languageSetting, CultureInfo.InstalledUICulture);
        CultureInfo.DefaultThreadCurrentCulture = culture;
        CultureInfo.DefaultThreadCurrentUICulture = culture;
        CultureInfo.CurrentCulture = culture;
        CultureInfo.CurrentUICulture = culture;
        return culture;
    }

    /// <summary>Saves pending settings, starts a new instance that waits for our mutex, then shuts this one down.</summary>
    public static void Restart(AppHost host)
    {
        ArgumentNullException.ThrowIfNull(host);
        host.FlushPendingWork();
        if (Environment.ProcessPath is not { Length: > 0 } path)
        {
            host.Log.Warn("restart skipped: process path is unknown");
            return;
        }

        try
        {
            Process.Start(new ProcessStartInfo(path) { UseShellExecute = false, ArgumentList = { RestartedArgument } })?.Dispose();
        }
        catch (Exception ex) when (ex is System.ComponentModel.Win32Exception or InvalidOperationException)
        {
            host.Log.Warn("restart failed to start a new instance", ex);
            return;
        }

        Application.Current.Shutdown(0);
    }
}
```

```csharp
namespace AITokenUsage.Core.Util;

/// <summary>Widget-sized time-to-reset text, the same in every language (v1.1 spec §2.2). Partial units are dropped.</summary>
public static class CompactDurationFormatter
{
    public static string Format(DateTimeOffset? resetsAt, DateTimeOffset now)
    {
        if (resetsAt is not { } at)
        {
            return "";
        }

        long totalMinutes = (long)Math.Floor((at - now).TotalMinutes);
        if (totalMinutes < 1)
        {
            return "<1m";
        }

        long days = totalMinutes / (24 * 60);
        long hours = totalMinutes / 60 % 24;
        long minutes = totalMinutes % 60;

        if (days >= 10)
        {
            return $"{days}d";
        }

        if (days > 0)
        {
            return hours > 0 ? $"{days}d{hours}h" : $"{days}d";
        }

        if (hours > 0)
        {
            return minutes > 0 ? $"{hours}h{minutes}m" : $"{hours}h";
        }

        return $"{minutes}m";
    }
}
```
